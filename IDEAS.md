# Idea backlog

Grouped by what they stress. Effort: S = an afternoon, M = a few sessions, L = a proper build.

## Voice and speech
- **Voice Design Zoo** (S): design 20–30 voices from absurd prompts ("a lighthouse keeper alone for 40 years", "a GPS that's given up", "a Victorian ghost who's into crypto"). Gallery of the prompt, the sample and how close it got.
- **Emotional range torture test** (S): one neutral sentence performed with every audio tag and emotion (whisper, shout, sarcasm, laughing mid-word, crying). Find where it cracks.
- **One line, 30 languages** (S): the same sentence in the same designed voice across every supported language, plus code-switching in the middle of a sentence.
- **Tongue-twister league** (S): ranked tongue twisters, nonsense words, IPA and made-up languages (Klingon-ish, Simlish-ish).

## Round-trips and loops
- **Telephone game** (S/M): TTS → STT → translate → TTS, run 20 times. Publish the drift as an audio timeline.
- **Echo chamber** (M): transcribe a generated clip, re-voice it in a different voice and accent each round, and see what survives.

## Agents
- **Choose-your-own-adventure narrator** (M): a voice agent whose workflow nodes are story branches, embedded on a page as a widget.
- **Dungeon master with tools** (L): an agent with code tools that keep inventory, roll dice and track HP. A test of agent state and tool use.
- **Unhelpful help desk** (S/M): an agent that is extremely polite and never solves anything. A test of personality, guardrails and turn-taking.
- **Interview the past** (M): agents playing *fictional* historical-era archetypes (a 1920s telegraph operator), with a knowledge base of public-domain sources.

## Multi-modal
- **Talking portraits** (M): generated image → designed voice → lipsync video. One short monologue per character.
- **60-second film** (L): a script, generated shots, a full-cast voiceover, SFX and music, cut together with ffmpeg.
- **Full-cast audiobook** (M): a public-domain short story (pre-1929) with a separate designed voice per character, SFX and a chapter player.
- **AI radio station** (L): designed DJ hosts, jingles, fake ads for fictional products, weather for imaginary cities. A looping web player.

## Tooling
- **Voice A/B blind test page** (S): visitors guess which clip is human and which is AI, or rate voice pairs.
- **Prompt cookbook** (ongoing): everything learned about prompting voice design, audio tags and agents, written down as it's learned.
